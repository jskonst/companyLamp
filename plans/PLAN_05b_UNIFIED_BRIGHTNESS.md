# План 05b — Единая Яркость Во Всех Режимах

## Цель
Сделать яркость глобальной и единообразной для всех режимов:
- одно общее значение яркости в настройках,
- единая функция применения яркости в рендере,
- одинаковое поведение при переключении между режимами.

Это гарантирует, что пользователь настраивает яркость один раз, и она действует везде.

---

## 05b.1 Проблема

Сейчас режимы могут задавать `FastLED.setBrightness(...)` по-разному (фиксированные значения, разные диапазоны).
Из-за этого при переключении режимов визуальная яркость скачет, а состояние яркости воспринимается как "локальное".

---

## 05b.2 Целевое правило

1. Источник истины по яркости — только `db[kk::bright]` (`cfg::bright()`).
2. Все `render*()` используют общий helper, а не свои "магические" значения.
3. Любые внутренние эффекты режимов (пульс/мигание) работают через коэффициент, а не через прямую установку абсолютной яркости.
4. Управление яркостью кнопкой (hold) работает глобально во всех режимах.

---

## 05b.2b Управление кнопкой по режимам

Итоговая раскладка кликов:

| Режим | 1 клик | 2 клика | hold |
|---|---|---|---|
| **LAMP** | power toggle | смена цвета | яркость |
| **POMODORO** | power toggle | управление сессией | яркость |
| **MOOD** | power toggle | — | яркость |
| **DND** | power toggle | — | яркость |

### 1 клик — везде power toggle

`1 клик` обрабатывается глобально в `button.ino` до mode-specific обработчиков.

`togglePowerGlobal()`:
- переключает `kk::power`,
- при включении из нулевой яркости поднимает яркость до минимально видимой (как сейчас в LAMP),
- сохраняет в БД.

```cpp
// button.ino — handleButtonClicks
if (clicks == 1) {
  togglePowerGlobal();
  return;
}
// дальше: mode-specific логика для clicks >= 2
```

### 2 клика в POMODORO — машина состояний сессии

| Состояние | Действие на 2 клика |
|---|---|
| IDLE | старт работы (`startPomoWork`) |
| WORK / BREAK_* | пауза |
| PAUSED | продолжить |
| DONE | следующий интервал (`startNextInterval`) |
| CONFIRMED | следующий интервал (`startNextInterval`) |

Смена цвета pomodoro убрана с кнопки — **только через web UI**.

### hold — глобальная яркость во всех режимах

`lampStep` / `lampReleaseStep` переносятся в общие обработчики `button.ino`.
В режимах POMODORO и DND добавляются `pomodoroStep`, `pomodoroReleaseStep`, `dndStep`, `dndReleaseStep` (или общий диспетчер).

## 05b.3 Базовый helper

Ввести общий helper в `mode.ino`:

```cpp
uint8_t globalBrightness255() {
  return map(cfg::bright(), 0, 100, 0, 255);
}

void applyGlobalBrightness(uint8_t effectScale255 = 255) {
  uint16_t v = (uint16_t)globalBrightness255() * effectScale255 / 255;
  FastLED.setBrightness((uint8_t)v);
}
```

`effectScale255` используется для дыхания/пульса (например, 80..255), но итог всегда ограничен глобальной яркостью.

---

## 05b.4 Правила для режимов

Для `renderLamp`, `renderPomodoro`, `renderMood`, `renderDND`:
- убрать прямые константы яркости (`40`, `60`, `80`, `100` и т.п.) из режима,
- заменить на `applyGlobalBrightness(...)`,
- для статичных сцен использовать `applyGlobalBrightness()` без scale,
- для эффектов мигания/пульса передавать `effectScale255` (0..255 от эффекта).

Для startup/системных сигналов:
- оставить отдельную яркость только для короткой служебной индикации старта,
- но после входа в рабочий loop — только глобальная яркость.

---

## 05b.5 UI и UX

- В UI остаётся один слайдер яркости (`kk::bright`).
- Цвет pomodoro управляется только через web UI (кнопка смены цвета убрана).
- Вне зависимости от активного режима изменение слайдера сразу влияет на текущий рендер.
- После перезагрузки сохраняется единое значение и применяется ко всем режимам.

## 05b.7 Критерии приёмки

- [ ] Яркость одинаково воспринимается в каждом режиме при одном и том же значении `kk::bright`
- [ ] Нет резких "скачков" яркости при переключении режимов
- [ ] Изменение яркости в UI моментально влияет на активный режим
- [ ] После reboot яркость восстанавливается и единообразно применяется
- [ ] В коде режимов нет прямых `FastLED.setBrightness(const)` без `applyGlobalBrightness`
- [ ] `1 клик` в любом режиме переключает power одинаково
- [ ] `2 клика` в POMODORO ведёт машину состояний сессии
- [ ] hold изменяет глобальную яркость во всех режимах
- [ ] Цвет pomodoro меняется только через web UI
