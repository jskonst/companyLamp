## Рекомендуемый порядок выполнения

```
01 → 02 → 04 → 04b → 03 → 03b → 05 → 06 → 07 → 08 → 09 → 10
```

Объяснение:
- **01, 02** — фундамент, без них всё остальное нестабильно
- **04** — система режимов нужна раньше WiFi, чтобы тестировать локально
- **03** — стартовая анимация и WiFi; к этому моменту уже есть рабочие режимы
- **05** — режим лампы завершается после системы режимов
- **06** — MQTT после того, как локальная механика работает
- **07–10** — сетевые режимы строятся на готовом MQTT
