## 2.2 Порт MQTT — хранить как число

**Файл:** `src/sets.cpp` + `src/sets.h`

Сейчас порт хранится строкой и парсится при каждом чтении:
```cpp
db.init(kk::port, "1883");                       // строка
uint16_t port() { return String(db[kk::port]).toInt(); }  // парсинг
```

Заменить на:
```cpp
db.init(kk::port, (uint16_t)1883);               // число
uint16_t port() { return (uint16_t)db[kk::port]; }
```

В `build()` поменять:
```cpp
b.Input(kk::port, "Порт", "1883");  // было
b.Input(kk::port, "Порт", 1883);    // стало (числовой тип)
```
