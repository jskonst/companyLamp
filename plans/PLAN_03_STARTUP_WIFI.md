# План 03 — Стартап: WiFi и визуальная индикация

## Цель
При включении лампа должна визуально сообщать о своём состоянии: имя лампы,
процесс подключения, результат. Пользователь понимает что происходит без Serial монитора.

---

## 3.1 Последовательность старта

```
Включение
    │
    ▼
Зелёное «дыхание» 2 сек    ← ждём клика для перехода в AP
    │
    ├─ клик ──────────────── Перейти в AP-режим (синее дыхание)
    │
    ▼
Попытка подключения к WiFi  ← зелёное дыхание, таймаут 15 сек
    │
    ├─ успех ─────────────── Показать имя лампы на кольце → рабочий режим
    │
    └─ таймаут / клик ─────── Перейти в AP-режим (синее дыхание)
```

---

## 3.2 Показ имени лампы на кольце (новая функция)

После успешного подключения: кольцо показывает первую букву имени лампы
в виде **N вспышек** (например, `AG_lamp_1` → 1 вспышка; `AG_lamp_2` → 2 вспышки).

Альтернатива — показать **IP-адрес** последним октетом: `.101` → 101 кратких вспышки
(слишком много). Лучше — **последняя цифра** имени лампы: `AG_lamp_1` → 1 вспышка белым.

```cpp
void showLampNumber() {
  // берём последний символ имени, если цифра — мигаем N раз
  const String name = cfg::local();
  char last = name.length() ? name[name.length() - 1] : '1';
  uint8_t n = (last >= '1' && last <= '6') ? (last - '0') : 1;

  for (uint8_t i = 0; i < n; i++) {
    fill_solid(leds, LED_AMOUNT, CRGB::White);
    FastLED.setBrightness(80);
    FastLED.show();
    delay(300);
    fill_solid(leds, LED_AMOUNT, CRGB::Black);
    FastLED.show();
    delay(300);
  }
  delay(500);
}
```

## 3.3 AP-режим: синее дыхание + имя точки

При входе в AP-режим:
- Анимация `loadAnimation(CRGB::Blue)` — дыхание синим.
- Имя точки: `WebLamp <последний_IP>` или просто `WebLamp` если IP неизвестен.
- Выход: клик по кнопке → перезагрузка (после сохранения настроек через веб).

---

## 3.4 Рефакторинг startup в отдельный файл

Вынести весь код старта из `setup()` в `startup.ino` (как в оригинале):

```
startup.ino
  ├── void startup()         ← всё что сейчас в setup()
  ├── void showLampNumber()  ← новая функция
  └── void enterAP()         ← режим точки доступа
```

`setup()` в main файле станет:
```cpp
void setup() {
  startup();
}
```

---

## 3.5 Таймаут подключения WiFi

Использовать `WiFiConnector` (уже подключён). Добавить визуальный таймаут:
- Каждые 5 секунд ожидания — короткая белая вспышка (пульс).
- После 15 секунд без подключения → уходим в AP.

## Проверка

- [ ] Включение: зелёное дыхание 2 сек
- [ ] Клик во время дыхания → синее дыхание (AP-режим)
- [ ] Успешное подключение → N вспышек белым (N = номер лампы)
- [ ] Через 15 сек без WiFi → синее дыхание (AP-режим)
- [ ] Имя AP видно в списке сетей как `WebLamp` или `WebLamp 192.168.x.x`
- [ ] После подключения лампа включается в последнем сохранённом состоянии
