# План 03 — Стартап: WiFi и визуальная индикация

## Цель
При включении лампа должна визуально сообщать о своём состоянии: процесс подключения и результат.
Пользователь понимает, что происходит, без Serial-монитора.

---

## 3.1 Последовательность старта

```
Включение
    │
    ▼
Зелёное «дыхание» 2 сек    ← ждём клика для перехода в AP
    │
    ├─ клик ─────────────── Перейти в AP-режим (синее дыхание)
    │
    ▼
Попытка подключения к WiFi  ← зелёное дыхание, таймаут 15 сек
    │
    ├─ успех ────────────── Короткое подтверждающее мигание → рабочий режим
    │
    └─ таймаут / клик ───── Перейти в AP-режим (синее дыхание)
```

---

## 3.2 Световая индикация вместо вывода адреса на кольце

IP-адрес на кольце не показываем (это слишком неудобно и нечитабельно для кольца).
После успешного подключения используем только простую световую индикацию:
- 2–3 коротких белых мигания как подтверждение «WiFi подключён».
- Далее переход в обычный рабочий режим.

Пример хелпера:
```cpp
void showWifiConnectedBlink() {
  for (uint8_t i = 0; i < 3; i++) {
    fill_solid(leds, LED_AMOUNT, CRGB::White);
    FastLED.setBrightness(80);
    FastLED.show();
    delay(180);

    fill_solid(leds, LED_AMOUNT, CRGB::Black);
    FastLED.show();
    delay(180);
  }
  delay(250);
}
```

---

## 3.3 AP-режим: синее дыхание + имя точки

При входе в AP-режим:
- Анимация `loadAnimation(CRGB::Blue)` — дыхание синим.
- Имя точки: `WebLamp <последний_IP_от_роутера>`.
- Если IP ещё неизвестен, использовать просто `WebLamp`.

Важно:
- Под «последним IP» понимается последний адрес, выданный WiFi-роутером в STA-режиме и сохранённый в настройках (`kk::ip`).
- Этот IP показывается в имени AP, а не на кольце.

---

## 3.4 Рефакторинг startup в отдельный файл

Вынести весь код старта из `setup()` в `startup.ino`:

```
startup.ino
  ├── void startup()                ← всё что сейчас в setup()
  ├── void showWifiConnectedBlink() ← новая индикация успеха WiFi
  └── void enterAP()                ← режим точки доступа
```

`setup()` в main файле станет:
```cpp
void setup() {
  startup();
}
```

---

## 3.5 Таймаут подключения WiFi

Использовать `WiFiConnector` (уже подключён). Добавить визуальный таймаут:
- Каждые 5 секунд ожидания — короткая белая вспышка (пульс).
- После 15 секунд без подключения → уходим в AP.

---

## Изменения файлов

| Файл | Действие |
|---|---|
| `src/startup.ino` | Перенести код из `setup()`, добавить `showWifiConnectedBlink()` |
| `src/WebLamp_v1.0.ino` | `setup()` → просто вызов `startup()` |
| `src/func.ino` | При необходимости оставить/перенести только общие анимационные хелперы |

---

## Проверка

- [ ] Включение: зелёное дыхание 2 сек
- [ ] Клик во время дыхания → синее дыхание (AP-режим)
- [ ] Успешное подключение → 2–3 белых мигания
- [ ] Через 15 сек без WiFi → синее дыхание (AP-режим)
- [ ] Имя AP видно как `WebLamp` или `WebLamp 192.168.x.x` (последний сохранённый IP от роутера)
- [ ] После подключения лампа включается в последнем сохранённом состоянии
