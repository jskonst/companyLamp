# companyLamp

Пара «ламп дружбы» на ESP8266 (Wemos D1 mini, PlatformIO, Arduino). Основано на [AlexGyver WebLamp](https://github.com/AlexGyver/WebLamp). Лампы обмениваются состоянием через MQTT (`GWL:` протокол, см. `src/mqtt.ino`).

## Сборка

```
pio run -t upload
pio device monitor -b 115200
```

## Управление без домашнего Wi-Fi (офлайн)

Лампа **никогда не блокируется** в ожидании Wi-Fi: кнопка, анимация и веб-интерфейс работают всегда.

| Ситуация | Что делает лампа |
|---|---|
| Первый запуск / нет сохранённой сети | сразу поднимает точку доступа `companyLamp-XXXXXX` |
| Сеть сохранена, но за 15 с нет IP | поднимает точку доступа, продолжает пытаться подключиться к роутеру раз в 30 с |
| Роутер пропал во время работы | через 15 с поднимает точку доступа |
| Роутер вернулся | подключается сама; точка гаснет через 60 с стабильной связи, если к ней никто не подключён |
| Клик кнопкой в первые 2 с после включения (мигает зелёным) | принудительно включить точку доступа |

### Как подключиться
1. Подключитесь телефоном к Wi-Fi `companyLamp-XXXXXX` (открытая; пароль можно задать `-DLAMP_AP_PASS=\"...\"` в `build_flags`, ≥8 символов).
2. Обычно портал открывается сам (captive portal). Если нет — откройте `http://192.168.4.1`.
3. В интерфейсе: вкл/выкл, яркость, цвет; ниже — SSID/пароль роутера и MQTT. «Save» сохраняет в EEPROM и переподключается **без перезагрузки**.
4. Кнопки «Переподключить Wi-Fi» и «Включить точку доступа» — ручное восстановление.

При наличии домашней сети интерфейс доступен по IP лампы в сети (виден в Serial и в портале) или `http://companylamp.local`.

Физическая кнопка: 1 клик — вкл/выкл, 2 — сменить цвет, 3 — подмигнуть, удержание — яркость. Работает и офлайн.

Пока поднята точка доступа, первый светодиод мигает синим. Пустой пароль в форме = не менять сохранённый.

**Точка доступа не постоянная:** поднимается только без связи с роутером (15 с) или по клику при старте; гаснет через 60 с стабильного STA без клиентов. Если нужна always-on — не вызывать `apStop()` (ценой лишнего эфира и открытой сети).

### Ограничения
- Без интернета MQTT недоступен: лампы не видят друг друга; управляется только локальная лампа.
- ESP8266 в режиме AP+STA при поиске роутера может переключить канал — подключённый к точке телефон иногда отваливается на секунду. Пока к точке есть клиент, попытки STA реже (раз в 2 мин).
- Настройки хранятся в эмулированной EEPROM (EEManager); формат `LampData` прежний, ранее сохранённые настройки читаются.
