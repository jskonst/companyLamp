# companyLamp

Группа ламп (до 20) на ESP8266 (Wemos D1 mini, PlatformIO, Arduino). Кольцо из 24 WS2812 показывает настроение владельца или среднее по группе. Обмен — MQTT, договорённость для брокера и прошивки одна: [`docs/protocol.md`](docs/protocol.md).

Основано на [AlexGyver WebLamp](https://github.com/AlexGyver/WebLamp). Старой пары `AG_lamp_1` / `AG_lamp_2` и публичного брокера больше нет.

## Сборка

По USB (крышка дна снята, micro-USB платы доступен):

```
pio run -e d1_mini -t upload
pio device monitor -b 115200
```

По Wi-Fi, если плата уже в корпусе:

```
pio run -e d1_mini_ota -t upload --upload-port 192.168.1.10
```

Пароль OTA по умолчанию `companylamp` (логин для браузера — `lamp`). Задаётся флагом `-DLAMP_OTA_PASS=\"...\"` в `platformio.ini`. Пустой пароль прошивка не соберёт. Если меняете пароль, поменяйте и `--auth=` у env `d1_mini_ota`.

Та же прошивка открывает страницу `http://<ip>/ota_update` (логин `lamp`, тот же пароль). Пока лампа сидит точкой доступа, IP для OTA — `192.168.4.1`, компьютер должен быть подключён к этой точке.

mDNS у каждой лампы свой: `http://companylamp-<id>.local`, где `<id>` — шесть hex-символов `ESP.getChipId()`.

## Кнопка

Числа кликов собраны в `GESTURE_*` (`include/group_logic.h`). Между кликами есть около 0,8 с.

| Действие | Что делает |
|---|---|
| 1 клик | подмигнуть остальным своим цветом |
| 2 клика | следующий шаг настроения `0 → 25 → 50 → 75 → 100 → 0` |
| 3 клика | вкл/выкл |
| 4 клика | мой цвет / среднее |
| 5 кликов | автономный режим вкл/выкл |
| удержание | яркость |
| клик в первые 2 с после включения | принудительно поднять точку доступа |

Питание, настроение, яркость, режим «среднее» и автономный режим пишутся в EEPROM и с кнопки, и из портала. Подмигивание не запоминается.

## Настроение и режимы

Цвет — шкала от красного к зелёному, не круг HSV: `0` плохо (красный), `50` жёлтый, `100` хорошо (зелёный). Формула оттенка FastLED — в протоколе: `hue(m) = m <= 50 ? m * 64 / 50 : 64 + (m - 50) * 32 / 50`.

- **Мой цвет** — кольцо показывает своё `m`.
- **Среднее** — среднее арифметическое `m` всех `online` в группе, включая эту лампу. `away` и `offline` не входят. Красная и зелёная дают жёлтую, а не синюю. Режим локальный, по MQTT не передаётся.
- **Автономный** — лампа публикует `away`, отключается и к брокеру не возвращается, пока режим не выключат. Не шлёт и не принимает подмигивания, в чужое среднее не попадает. Кольцо показывает свой цвет, последний светодиод горит тусклым белым. Флаг лежит в EEPROM.

Пока в группе есть хотя бы одна другая лампа `online`, кольцо слегка «дышит». Синее мигание первого светодиода — поднята точка доступа.

## Портал

Точка `companyLamp-<id>` или адрес в домашней сети. В форме: группа, хост и порт брокера, логин и пароль брокера, имя владельца (необязательно, уходит в поле `n`). Плюс SSID роутера.

Пароли Wi-Fi, брокера и точки в HTML не подставляются. Пустое поле значит «не менять». Чтобы убрать пароль точки — кнопка «Сбросить пароль точки». Логин брокера и имя видны и сохраняются как введены, пустой логин пароль брокера не отправляет.

Пустая группа или пустой хост — лампа работает локально и к MQTT не подключается.

На странице видно, сколько ламп `online` и список: id, имя, настроение, статус.

### Точка доступа

По умолчанию **открытая**. Пароль (не короче 8 символов):

- флаг сборки `-DLAMP_AP_PASS=\"secret12\"`, или
- поле в портале (если задано, оно важнее флага).

Сброс поля возвращает пароль из флага, а если флага нет — снова открытую сеть.

| Ситуация | Что делает лампа |
|---|---|
| Первый запуск / нет сохранённой сети | сразу поднимает точку `companyLamp-<id>` |
| Сеть сохранена, но за 15 с нет IP | поднимает точку, пробует роутер раз в 30 с |
| Роутер пропал во время работы | через 15 с поднимает точку |
| Роутер вернулся | подключается сама; точка гаснет через 60 с стабильной связи, если к ней никто не подключён |
| Клик в первые 2 с (мигает зелёным) | принудительно включить точку |

Пока к точке кто-то подключён, попытки STA реже (раз в 2 минуты): ESP8266 при поиске роутера может сменить канал. Без интернета лампы друг друга не видят, локальное управление остаётся.

**После этой прошивки настройки старой пары не читаются.** Ключ EEPROM сменён с `a` на `b`: Wi-Fi, группа и брокер вводятся заново. Так старый образ `LampData` не попадает в новые поля.

## MQTT для DevOps

Готовый брокер — [`infra/broker`](infra/broker) (Mosquitto, анонимный вход выключен). Пользователю группы выдают ACL `lamp/<группа>/#`, в портале указывают хост, порт **1883**, логин и пароль. Имя хоста лучше короче 32 символов. TLS 8883 прошивка не открывает: для ESP8266 оставлен открытый 1883, как в инструкции брокера для первого запуска.

Авторитетный текст протокола — [`docs/protocol.md`](docs/protocol.md). Ниже то же дерево, чтобы собрать ACL, не листая прошивку.

`id` лампа берёт из chip id, в портале его нет. `group` — имя из портала: латиница, цифры, `-`, до 20 символов, регистр важен. Client id: `lamp-<id>`, clean session, keepalive 15 с.

| Топик | Retained | QoS | Содержимое |
|---|---|---|---|
| `lamp/<group>/<id>/status` | да | 1 | `online`, `away` или `offline` |
| `lamp/<group>/<id>/state` | да | 1 | `{"m":75,"n":"Женя"}` |
| `lamp/<group>/<id>/wink` | нет | 0 | `{"h":96}` |

Лампа подписана на `lamp/<group>/+/status`, `lamp/<group>/+/state` и `lamp/<group>/+/wink` и игнорирует сообщения со своим `id`.

- **status.** Last Will при подключении: `offline`, retained, QoS 1. Брокер публикует его сам примерно через 1,5 keepalive (~22 с), если сессия умерла без DISCONNECT. Сразу после подключения лампа пишет `online`. В автономном режиме пишет `away` и отключается чисто, чтобы Will не затёр `away`.
- **state.** `m` — настроение 0…100, сохраняется в EEPROM. `n` — имя, необязательно; если имени нет, лампа шлёт `{"m":50}` без поля `n`. Сообщение retained, новая лампа видит всех сразу.
- **wink.** `h` — оттенок FastLED (0–255) настроения того, кто нажал. Остальные мигают этим цветом около 1,2 с и возвращаются к своему. Свой цвет получателя не меняется.

Общий пользователь брокера: чтение и запись `lamp/#`.

Отдельный пользователь на лампу: запись `lamp/<group>/<id>/#`, чтение `lamp/<group>/#` (подписки со `+` укладываются в этот фильтр).

Смена группы не стирает старые retained на брокере — их снимают вручную, иначе в старой группе лампа так и останется `online`.

Пока Wi-Fi есть, а брокер нет, `connect()` не держит loop: клиент асинхронный, повтор с паузой 2…30 с. Коротко заблокироваться может только DNS ещё не известного имени (до 500 мс) и только если в этот момент не набирается серия кликов.

## Железо

Пины не менялись.

| Функция | GPIO | D1 mini |
|---|---|---|
| Данные WS2812 | 14 | D5 |
| Кнопка | 16 | D0, `BTN_LEVEL 1`, внешний подтяг к GND |
| PIR | 12 | D6, `USE_PIR 0`. В групповом протоколе датчик не передаётся |

Лимит тока ленты: `FastLED.setMaxPowerInVoltsAndMilliamps(5, 800)`. Питание и посадка — `hardware/power.md`.
