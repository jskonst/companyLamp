# WebLamp — умная командная лампа на D1 Mini

Лампа из 24 NeoPixel LED с 4 режимами работы, управлением кнопкой и web-интерфейсом.

---

## Режимы

Кольцо из 24 LED разбито на 4 секции по 4 LED. При переключении режима загорается соответствующая секция на 2 секунды, затем включается рендер нового режима.

| # | Режим | LED | Цвет секции | Описание |
|---|---|---|---|---|
| 0 | **LAMP** | 0–5 | Тёплый белый | Обычная лампа с регулировкой цвета и яркости |
| 1 | **POMODORO** | 6–11 | Оранжевый | Таймер Помодоро с прогрессом на кольце |
| 2 | **MOOD** | 12–17 | Зелёный | Настроение: показывает среднее по команде, личное настраивается |
| 3 | **DND** | 18–23 | Красный | Не беспокоить |

Размер секции вычисляется автоматически: `LED_AMOUNT / MODE_COUNT` (сейчас 24 / 4 = 6).

## Управление кнопкой

### Переключение режимов
| Клики | Действие |
|---|---|
| **3 клика** | Следующий режим (LAMP → POMODORO → MOOD → DND → LAMP) |
| **4 клика** | Предыдущий режим |
| **5+ кликов** | Wink — мигнуть всем лампам группы (уведомить команду) |

### Режим LAMP
| Действие | Результат |
|---|---|
| 1 клик | Вкл / Выкл |
| 2 клика | Следующий цвет (8 шагов по HSV) |
| Удержание | Регулировка яркости (направление меняется при отпускании) |

### Режим POMODORO

Таймер Помодоро с прогрессом на кольце. Кольцо делится на сегменты — количество задаётся в настройках.

#### Состояния

| Состояние | Что показывает кольцо |
|---|---|
| **IDLE** | Фоновый цвет (тусклый), таймер сброшен |
| **WORK** | Кольцо заполняется цветом работы блок за блоком слева направо |
| **BREAK** | Кольцо заполняется зелёным (короткий / длинный перерыв) |
| **PAUSED** | Прогресс заморожен, заполненная часть мигает цветом паузы |
| **DONE** | Всё кольцо мигает белым 5 раз, затем переходит в CONFIRMED |
| **CONFIRMED** | Секция 2 медленно пульсирует оранжевым — ждёт старта следующего |

#### Управление кнопкой

| Действие | Состояние | Результат |
|---|---|---|
| **1 клик** | IDLE | Старт рабочего интервала |
| **1 клик** | WORK / BREAK | Пауза |
| **1 клик** | PAUSED | Продолжить с того же места |
| **1 клик** | DONE | Остановить мигание → CONFIRMED |
| **1 клик** | CONFIRMED | Запустить следующий интервал |
| **2 клика** | IDLE | Сменить цвет работы (+32 по HSV, 8 шагов) |
| **2 клика** | Любое другое | Пропустить к следующему интервалу |

#### Логика чередования интервалов

```
IDLE → [1 клик] → WORK → [истёк / 2 клика] → DONE → [1 клик] → CONFIRMED
                                                                      │
                                              ┌───────────────────────┘
                                              ▼
                                     BREAK_SHORT или BREAK_LONG
                                     (длинный — каждые N помодоро)
                                              │
                                    [истёк / 2 клика]
                                              │
                                           DONE → CONFIRMED → WORK ...
```

После заданного числа помодоро вместо короткого перерыва — длинный. Счётчик сбрасывается при старте из IDLE.

### Режим MOOD *(в разработке — Plan 08)*
| Действие | Результат |
|---|---|
| 1 клик | Отправить текущее настроение команде |
| Удержание | Прокрутка личного цвета (зелёный → красный) |

### Режим DND *(в разработке — Plan 07)*
| Действие | Результат |
|---|---|
| 1 клик | Вкл / Выкл режим «не беспокоить» |

## Web-интерфейс

Открыть в браузере: `http://<IP-адреса лампы>/`

IP-адрес отображается в настройках. При первом запуске (или кнопкой во время загрузки) лампа поднимает точку доступа `WebLamp` для настройки WiFi.

**Переключение режимов через web:** табы на главной странице (в разработке — Plan 04+).

## MQTT

Лампы общаются через внешний MQTT-брокер. Каждая лампа публикует своё состояние
и подписывается на состояния других ламп в той же группе.

### Настройки подключения

| Поле | Описание | Пример |
|---|---|---|
| **Имя лампы** | Уникальный идентификатор в группе | `lamp_1` |
| **Группа** | MQTT-пространство имён; лампы видят только друг друга внутри одной группы | `office` |
| **MQTT хост** | Адрес брокера | `broker.hivemq.com` |
| **Порт** | Стандартный MQTT-порт | `1883` |

Настройки задаются в веб-интерфейсе → меню **WiFi**.

### Выбор брокера

**Публичные бесплатные** (для быстрого старта, без регистрации):

| Брокер | Хост | Примечание |
|---|---|---|
| HiveMQ Public | `broker.hivemq.com` | Надёжный, без регистрации, данные публичны |
| Eclipse Mosquitto | `test.mosquitto.org` | Тестовый, нет гарантий сохранности |

> Публичные брокеры не шифруют данные и видны всем. Для реального использования рекомендуется свой брокер.

**Self-hosted** (рекомендуется):

| Вариант | Описание |
|---|---|
| **Mosquitto** | Самый лёгкий, работает на Raspberry Pi, устанавливается в одну команду |
| **Home Assistant** | Встроенный Mosquitto add-on, если уже используется HA |
| **EMQX** | Больше возможностей, есть веб-дашборд, чуть тяжелее |

Пример установки Mosquitto на Raspberry Pi / Ubuntu:
```bash
sudo apt install mosquitto mosquitto-clients
sudo systemctl enable mosquitto
```

### Аутентификация

MQTT-протокол поддерживает подключение с логином и паролем — брокер может требовать
учётные данные для подключения. PubSubClient (используемая библиотека) это поддерживает.

> Поля «логин» и «пароль брокера» будут добавлены в настройки в рамках Plan 06.
> Сейчас лампа подключается без аутентификации.

## Структура кода

| Файл | Содержимое |
|---|---|
| `WebLamp_v1.0.ino` | Инициализация, `setup()`, `loop()` |
| `mode.h` / `mode.ino` | Система режимов: переключение, индикатор, диспетчер рендера |
| `mode_lamp.ino` | Режим LAMP |
| `mode_pomodoro.ino` | Режим POMODORO: машина состояний, визуализация, синхронизация с web |
| `mode_mood.ino` | Режим MOOD (стаб → Plan 08) |
| `mode_meeting.ino` | Wink-эффект и MQTT publish (заменяет Plan 09, привязан к 5 кликам) |
| `mode_dnd.ino` | Режим DND (стаб → Plan 07) |
| `button.ino` | Диспетчер кнопки |
| `sets.h` / `sets.cpp` | База данных настроек (GyverDB), web-интерфейс настроек |
| `startup.ino` | WiFi подключение при загрузке |
| `mqtt.ino` / `mqtt.h` | MQTT: подключение, heartbeat, callback, офлайн-режим |
