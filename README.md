# WebLamp — умная командная лампа на D1 Mini

Лампа из 24 NeoPixel LED с 5 режимами работы, управлением кнопкой и web-интерфейсом.

---

## Режимы

Кольцо из 24 LED разбито на 5 секций по 4 LED. При переключении режима загорается соответствующая секция на 2 секунды, затем включается рендер нового режима.

| # | Режим | LED | Цвет секции | Описание |
|---|---|---|---|---|
| 0 | **LAMP** | 0–3 | Тёплый белый | Обычная лампа с регулировкой цвета и яркости |
| 1 | **POMODORO** | 4–7 | Оранжевый | Таймер Помодоро с прогрессом на кольце |
| 2 | **MOOD** | 8–11 | Зелёный | Настроение: показывает среднее по команде, личное настраивается |
| 3 | **MEETING** | 12–15 | Голубой | Состояние при вызове на митинг |
| 4 | **DND** | 16–19 | Красный | Не беспокоить |

LED 20–23 зарезервированы для будущего статус-индикатора.

## Управление кнопкой

### Переключение режимов
| Клики | Действие |
|---|---|
| **3 клика** | Следующий режим (LAMP → POMODORO → MOOD → MEETING → DND → LAMP) |
| **4 клика** | Предыдущий режим |
| **5+ кликов** | Позвать на митинг из **любого** режима (голубая вспышка) |

### Режим LAMP
| Действие | Результат |
|---|---|
| 1 клик | Вкл / Выкл |
| 2 клика | Следующий цвет (8 шагов по HSV) |
| Удержание | Регулировка яркости (направление меняется при отпускании) |

### Режим POMODORO *(в разработке — Plan 10)*
| Действие | Результат |
|---|---|
| 1 клик | Старт / Пауза / Продолжить |
| 2 клика (в паузе/ожидании) | Пропустить к следующему интервалу |
| 2 клика (IDLE) | Сменить базовый цвет |

### Режим MOOD *(в разработке — Plan 08)*
| Действие | Результат |
|---|---|
| 1 клик | Отправить текущее настроение команде |
| Удержание | Прокрутка личного цвета (зелёный → красный) |

### Режим MEETING *(в разработке — Plan 09)*
| Действие | Результат |
|---|---|
| 1 клик | Отправить / Подтвердить участие |
| 2 клика | Отменить |

### Режим DND *(в разработке — Plan 07)*
| Действие | Результат |
|---|---|
| 1 клик | Вкл / Выкл режим «не беспокоить» |

## Web-интерфейс

Открыть в браузере: `http://<IP-адреса лампы>/`

IP-адрес отображается в настройках. При первом запуске (или кнопкой во время загрузки) лампа поднимает точку доступа `WebLamp` для настройки WiFi.

**Переключение режимов через web:** табы на главной странице (в разработке — Plan 04+).

## Загрузка прошивки

```bash
# сборка и загрузка
pio run --target upload

# только сборка
pio run
```

## Структура кода

| Файл | Содержимое |
|---|---|
| `WebLamp_v1.0.ino` | Инициализация, `setup()`, `loop()` |
| `mode.h` / `mode.ino` | Система режимов: переключение, индикатор, диспетчер рендера |
| `mode_lamp.ino` | Режим LAMP |
| `mode_pomodoro.ino` | Режим POMODORO (стаб → Plan 10) |
| `mode_mood.ino` | Режим MOOD (стаб → Plan 08) |
| `mode_meeting.ino` | Режим MEETING + быстрый вызов митинга (стаб → Plan 09) |
| `mode_dnd.ino` | Режим DND (стаб → Plan 07) |
| `button.ino` | Диспетчер кнопки |
| `sets.h` / `sets.cpp` | База данных настроек (GyverDB), web-интерфейс настроек |
| `startup.ino` | WiFi подключение при загрузке |
| `mqtt.ino` | MQTT (в разработке — Plan 06) |
